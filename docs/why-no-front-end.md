# Why there is no front end

The work is importing a population, checking it, investigating exceptions and documenting review. An agent can run each operation against a database, while read-only HTML gives the reviewer a stable document.

There is no drag-and-drop data preparation, interactive chart exploration, mobile app, offline multi-device sync or concurrent spreadsheet editing. The embedded database is for one local operator at a time. A shared Postgres instance needs an access design and backups. RLS is enabled without public policies: use a trusted owner connection, never an anonymous browser connection.

The reports do not provide row-level access controls. Protect the files and do not host them publicly. Any web interface, specialist statistical procedures or integration is scoped and tested separately through Omni by Enterprise DNA.

This is a focused alternative for transaction testing and evidence review, not a claim of feature parity with IDEA. The source records remain yours. Your professional judgment remains yours too.
